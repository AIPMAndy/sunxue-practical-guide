# SunXue Practical Guide (孙学实操攻略)

An independently authored, evidence-first practice guide by AI 酋长 Andy, based on a long-form public interview featuring Justin Sun and Alan Shao. This is not affiliated with the interview participants.

The exercises focus on identifying existing skills, investigating user needs, testing a small prototype, learning clear communication, and deciding whether to continue based on real feedback.
