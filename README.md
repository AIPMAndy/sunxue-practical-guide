## 这份攻略能帮你做什么

孙宇晨的资金、产品、用户、团队和传播资源，大多数人复制不了。这里挑能落到普通人生活里的部分：先盘点自己手里有什么牌，再去找到确实有需求的人，做一个小样，问真实反馈，最后决定这件事值不值得继续。

完整文章保留了 Andy 亲自看将近三小时原视频的感受、AI+IP 表达研究、内容和咨询经历，以及运动、全球市场和 AI 工作流的实际尝试。**已知事实和作者判断分开写，没发生的客户故事不编造。**

### 七天怎么做

| 天数 | 做什么 | 完成后留下什么 |
|---|---|---|
| Day 1 | [盘点手里的牌](docs/7-day-challenge.md#day-1--盘点资源) | 一页个人资源表 |
| Day 2 | [探图](docs/7-day-challenge.md#day-2--探图) | 20 条真实需求、5 个已有方案及出处 |
| Day 3 | [联系真人](docs/7-day-challenge.md#day-3--联系真人) | 联系 5 人，尽量聊成 1—2 人，或真实拒绝记录 |
| Day 4 | [做小样](docs/7-day-challenge.md#day-4--做小样) | 一份可以让人试的成果 |
| Day 5 | [学表达](docs/7-day-challenge.md#day-5--学表达) | 一段 1 分钟视频或一篇短文 |
| Day 6 | [测试付费](docs/7-day-challenge.md#day-6--测试付费意愿) | 询价、拒绝或实际支付记录 |
| Day 7 | [复盘](docs/7-day-challenge.md#day-7--算账与取舍) | 继续 / 修改 / 停止的证据说明 |

本项目展示的是小规模商业研究、内容表达和行动训练，不包含数字资产推荐、交易策略或收益预测。

## 下载与使用

直接打开 [在线阅读与七天打卡](https://aipmandy.github.io/sunxue-practical-guide/)，无需注册。源码仓库：[AIPMAndy/sunxue-practical-guide](https://github.com/AIPMAndy/sunxue-practical-guide)。

点击 GitHub 的 **Code → Download ZIP**，解压后双击 `index.html`，即可离线打开阅读和打卡页。你也可以直接阅读 [GUIDE.md](GUIDE.md) 和 [prompt 指令库](prompts/start-here.md)。打卡记录只存当前浏览器，清理浏览器数据就会消失。

如果要在公众号发表，使用 [文章 HTML](wechat-article.html) 预览、复制正文，并把 `assets` 里的配图逐张上传至公众号素材库。编辑器可能去除原图链接，最终请在手机上预览。

