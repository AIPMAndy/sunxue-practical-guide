# 内容证据与风险边界

| 类型 | 可以怎么写 | 不能怎么写 |
|---|---|---|
| 访谈观点 | “某位嘉宾在访谈中表示……” | “科学已经证明……” |
| 用户需求 | 附日期、原话、来源的匿名样本 | AI 编造的用户故事 |
| 方法论 | “建议先做 7 天训练” | “保证七天赚到钱” |
| 商业数据 | 合同、实付、退款、成本、工时分别记录 | 把意向当成交、把收款当利润 |
| 健康建议 | 提醒个人评估，咨询合格专业人士 | 强行照搬名人的饮食/训练习惯 |
| AI 建议 | 留下来源与独立验证记录 | “AI 说了就是对的” |

## 内容发布核对

- [ ] 区分嘉宾观点、作者推导、读者练习与虚拟演示。
- [ ] 有时间敏感性的数字标注查询时间并独立核验。
- [ ] 不展示可识别的客户简历、手机号、身份证等私人数据。
- [ ] 不提供代币交易、借贷投资或保证收益的诱导。
- [ ] 不暗示嘉宾官方合作或背书。
- [ ] 图片为原创教学图或获得许可的素材。
