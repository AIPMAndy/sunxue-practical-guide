# 人物案例的对抗式检查

研究成功人物时，最容易忽略他当时已经拥有的资源。拆历史事件，可以用下面五个问题逐项核对。

1. **有没有起点差异？** 比如收购成熟产品需要资金与团队，普通人只能从小型合作或渠道试验入手。
2. **有没有把同时发生说成因果？** 获得曝光后出现其他商业进展，不等于曝光导致了全部成果。
3. **有没有看不到的失败项目？** 访谈往往集中讲成功事件，不能由此推断所有尝试都成功。
4. **有没有把用户规模当作商业价值？** 用户量、活跃用户、收入、利润、现金到账都不一样。
5. **有没有把自述当作验证？** 当事人说法要与公开记录和独立资料核对。

## 普通人的替代练习

- 收购用户网络 → 寻找已经聚集目标用户的合作渠道。
- 大型公关事件 → 用真实服务、可核查案例和诚实表达获得信任。
- 大成本试验 → 用三天内能完成的小样，先观察有没有真实用户愿意试。
- 对外发布结论 → 区分自己看到的事实、个人判断与尚未核实的推测。
